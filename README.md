> A modern, high-performance personal portfolio and engineering showcase designed with rich dark aesthetics, interactive terminal shell, dynamic role filtering, and comprehensive project architectures.

---

## 🌟 Key Features

- **🎯 Role Lens Discipline Switcher**: Dynamically adapts the entire showcase across multiple engineering disciplines (*All Disciplines*, *AI & Machine Learning*, *Generative AI & LLMs*, *Data Science & Analytics*, *SDE & Web Development*).
- **💻 Interactive Command Terminal**: Built-in CLI shell supporting directives (`help`, `resume`, `skills`, `projects`, `contact`, `clean`) with command history navigation.
- **🛠️ Featured Engineered Systems**: Deep-dive technical breakdown of 13 production systems and AI research projects with architectural highlights, key metrics, and technology badges.
- **🏆 Competitions & Verified Credentials**: Dual-column showcase highlighting hackathon placements and verified industry certifications from Google Cloud, IBM, Microsoft, Anthropic, and NVIDIA.
- **⚡ Technical Arsenal Marquee**: Perpetual, hardware-accelerated icon marquee featuring full-stack, AI/ML, and DevOps toolsets with interactive tooltips.
- **📄 Instant Résumé Access**: Embedded PDF previewer and direct one-click download channels.

## 🏗️ Tech Stack

- **Frontend**: React 19, TypeScript, Vite

## 🚀 Getting Started

### Prerequisites

- Node.js (v18.0.0 or higher)
- npm or yarn / pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Me-HimanshuJain/Portfolio.git
   cd Portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
